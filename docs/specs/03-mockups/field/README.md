# Fidero Field mockups in Bloc

Six Fidero Field screens in the Bloc direction (document 03, sections 6.1a and 6.1c), drawn from wireframes W-17, W-18, W-30 and W-40. They are the source files of row 5 on the design canvas at https://claude.ai/artifact/5EPmPiRm2cBuJKmy3AJb3K. Each file is one 390 × 844 artboard in the canvas's `.dc.html` format.

| File | Screen | Role | Wireframe |
|---|---|---|---|
| `FieldJobs.dc.html` | My jobs, today | Inspector | SCR-MOB-02 |
| `FieldInspection.dc.html` | Inspection checklist and result | Inspector | W-18, SCR-MOB-09 and 11 |
| `FieldCapture.dc.html` | Check this photo: the seal, position, time, fingerprint | Any | SCR-MOB-06 |
| `FieldMilestone.dc.html` | Submit a milestone while offline | Contractor | W-17, SCR-MOB-07 |
| `FieldVisit.dc.html` | Check in at the address | Carer | W-30, SCR-MOB-14 |
| `FieldPay.dc.html` | My pay, with no verdict colour anywhere | Contracted professional | W-40, SCR-MOB-19 |

All names, amounts, references, places and dates are sample data.
