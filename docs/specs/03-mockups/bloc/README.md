# Bloc mockups

The 12 Bloc screens the founder chose for the client app on 12 November 2026 (document 03, section 6.1a). They are the source files of the design canvas at https://claude.ai/artifact/5EPmPiRm2cBuJKmy3AJb3K, row 4. The canvas also holds the three directions not chosen: Pulse, Lime and Clarity.

Each file is one 390 × 844 artboard in the canvas's `.dc.html` format. They render inside the canvas, which supplies `support.js`. The welcome screen points to a photograph stored on the canvas; it has no licence for use in the app yet (03 DQ-22).

| File | Screen |
|---|---|
| `BlocWelcome.dc.html` | Welcome |
| `BlocHome.dc.html` | Home with account cards side by side |
| `BlocCases.dc.html` | Property |
| `BlocProgress.dc.html` | Case progress |
| `BlocReport.dc.html` | Land report |
| `BlocEvidence.dc.html` | Evidence (not yet in the app: the API has no photo list) |
| `BlocApprove.dc.html` | Approve a release |
| `BlocApproved.dc.html` | Approval done |
| `BlocFamily.dc.html` | Family |
| `BlocInvoice.dc.html` | Hospital bill |
| `BlocProjects.dc.html` | Projects |
| `BlocAccount.dc.html` | Account |

All names, amounts, references and dates are sample data.
