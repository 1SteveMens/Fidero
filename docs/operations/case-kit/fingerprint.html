Fingerprint tool

Gives every file a fingerprint (SHA-256): 64 letters and numbers that change completely if even one dot in the file changes. Log the fingerprint the day a file arrives. Later, anyone can prove the file has not been altered. Files never leave this computer. Nothing is uploaded; the page works with the internet off.

1. Fingerprint new evidence

Drop files or a whole case folder here

or

FileFolderSizeFingerprint (SHA-256)

Then open the tracker's Evidence log tab, click the first empty cell in column A, and paste. It fills Case ID, File name, Fingerprint, Folder, Logged on and Logged by. Add what each file shows, who took it, when and where.

2. Check a file

Has this file changed since it was logged? Paste the fingerprint from the tracker, then choose the file. Use it for a released report a client sends back, or any evidence before you rely on it.

The rules

  • Fingerprint the original file from the phone or scanner. Never one sent by WhatsApp, which changes it.
  • Never edit, crop, trim or compress evidence. A changed file gets a new fingerprint.
  • Name files C001_F_2027-01-20_pillar-ne.jpg: case, folder letter, date taken, a few words.
  • The same fingerprint in two cases means the same file was used twice. The tracker flags it; find out why.
